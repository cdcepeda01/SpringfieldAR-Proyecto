Versión funcional y completa de la aplicación de Realidad Aumentada desarrollada en Unity con Vuforia para la materia de Realidad Mixta.
La aplicación incluye:
- Menú principal con acceso a las experiencias ImageTarget, GroundPlane y MidAir.
- Reconocimiento de múltiples Image Targets con personajes de Los Simpson.
- Sistema de cambio entre diferentes modelos 3D sobre un target especial.
- Visualización de contenido 3D sobre superficies mediante Ground Plane.
- Posicionamiento de objetos 3D en el espacio mediante MidAir.
- Navegación entre escenas y botones de regreso al menú principal.
- Compilación para dispositivos Android.
Archivo incluido: APK instalable para Android.
